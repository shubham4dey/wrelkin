# WRELKIN INDIA PRIVATE LIMITED — Frontend Starter

Premium renewable-energy EPC website structure.

## Stack
- React + Vite
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- React Router
- Lucide React
- Swiper
- React Hook Form
- Axios
- Lenis (optional)

## Start
1. Extract/open this folder.
2. Run `npm install`
3. Run `npm run dev`

## Architecture
- `src/components/` reusable UI
- `src/pages/` route-level pages
- `src/data/` temporary frontend data
- `src/routes/` routing
- `public/` images, videos, brochures and documents
- `server/` backend blueprint only

## Important
The JSX files are intentionally lightweight placeholders. Build Home first, then replace placeholders with the premium WRELKIN design system.
